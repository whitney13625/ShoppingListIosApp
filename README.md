# Shopping List — Native iOS Client (SwiftUI)

A native iOS implementation of the shopping list domain, built with SwiftUI. Part of a deliberate cross-stack study where the same domain is implemented across three different technologies to compare architecture decisions, development experience, and trade-offs.

## Related Repositories

| Stack | Repository |
|-------|-----------|
| Backend API | [TypeScript / Node.js / PostgreSQL](https://github.com/whitney13625/ShoppingListTypeScriptBackend) |
| Cross-platform client | [React Native / Expo](https://github.com/whitney13625/ShoppingListIosReactNativeApp) |
| Native iOS client | This repository |

## Stack

- **Language:** Swift
- **UI Framework:** SwiftUI
- **Architecture:** MVVM

## Purpose

Built to explore native iOS development patterns using SwiftUI, and to contrast the native development experience against the React Native implementation of the same domain. Working across all three layers — backend, native, and cross-platform — provides a fuller picture of the trade-offs involved in mobile and full-stack architecture decisions.
